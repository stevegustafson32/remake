# Remake of {{url}}

Made with [Remake](https://github.com/stevegustafson32/remake), a fork of [rubenhassid1/remake](https://github.com/rubenhassid1/remake) with the Vercel step removed. Private until it's yours.

| Where | What |
| --- | --- |
| `site/` | The website. `remake serve` runs it at http://127.0.0.1:4310. |
| `site/_remake/` | Proof page (original vs remake, drag to compare) and the swap board. |
| `MAKE-IT-YOURS.md` | Everything that still belongs to the original, and what Claude needs from you. |
| `REPORT.md` | The latest score and what's left. |
| `remake/content.json` | The swap file: fill a slot's `swap`, then `remake apply`. |
| `remake/sources/` | The original's source files, when it publishes source maps. |

Until the swap board says 100%, this is a copy of someone else's work. Keep it private and on your machine.
